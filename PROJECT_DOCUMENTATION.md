# WOTER - Система учета водоснабжения

## Что это

**WOTER** — это информационная система для управления работой водоснабжения. Программа помогает вести учет клиентов, платежей, начислений и других операций, связанных с поставкой воды.

## Для чего нужна

Система предназначена для отделов водоснабжения, бухгалтерии и операторов, которые работают с абонентами. Она заменяет рудовой учет в Excel и бумажные документы, объединяя все процессы в одном месте.

## Что делает система

### 1. Управление клиентами
- Ведение базы данных абонентов (физических и юридических лиц)
- Поиск клиентов по лицевому счету или ФИО
- Добавление и редактирование информации о клиентах
- Учет адресов, количества проживающих, наличия водомеров
- Разделение на квартирных (по норме) и частных (с водомером) клиентов

### 2. Учет платежей
- Регистрация приемов платежей от клиентов
- Учет оплат по основным тарифам и субсидиям
- Автоматический расчет налогов из суммы оплаты
- Импорт платежей из Excel-файлов (пакетная загрузка)
- Просмотр истории оплат с фильтрацией по месяцам и годам

**Где применяется:** В кассе водоснабжения, бухгалтерии для учета поступлений денег.

### 3. Сальдо и начисления
- Отображение текущего баланса каждого клиента
- Начисление платы за воду по тарифам
- Учет входящего/исходящего сальдо
- Контроль движения средств (дебет/кредит)
- Разделение статистики по типам клиентов (квартирные, частные, с водомерами)
- Месячное закрытие-period (переход на следующий месяц)

**Где применяется:** Бухгалтерия для расчета monthly начислений, контроль задолженности.

### 4. Работа со станциями
- Учет водопроводных станций
- Привязка клиентов к определенным станциям
- Просмотр клиентов по станциям

**Где применяется:** Управленческий учет, распределение Responsibilities между станциями.

### 5. Показания счетчиков
- Учет показаний водомеров
- Ввод фактического потребления воды
- Расчет начислений на основе реальных показаний

**Где применяется:** Операторы, принимающие показания от клиентов с индивидуальными счетчиками.

### 6. Субсидии
- Учет выплат субсидий клиентам
- Регистрация сумм субсидий separate от обычных оплат

**Где применяется:** Социальные службы, бухгалтерия для учета государственных Subsidy.

### 7. Справочники
- Унифицированные списки: улицы, дома, тарифы, типы клиентов
- Централизованное управление классификаторами
- Быстрый доступ к справочной информации при работе с клиентами

**Где применяется:** Все работники используют справочники для однородного учета.

### 8. Отчетность и печать
- Формирование квитанций для клиентов
- Печать отчетов о дислокации домов
- Отчеты по оборотным ведомостям
- Отчеты о поступлении платежей
- Выбор периода для отчетов

**Где применяется:** Бухгалтерия, кассиры, клиенты (квитанции), руководство (отчеты).

### 9. События и логирование
- Автоматическая запись важных действий в системе
- Протоколирование операций (добавление клиента, платежи, редактирование)
- Просмотр истории изменений

**Где применяется:** Администраторы, аудит, контроль действий сотрудников.

## Где можно применить

1. **Городские/районные водоснабжения** — основной вариант использования для учетаThousands абонентов
2. **Сельские водопроводные службы** — учет небольшой группы клиентов
3. **Управляющие компании** — если они занимаются поставкой воды
4. **Частные водоснабжающие компании** — коммерческий учет

## Основные роли пользователей

- **Оператор/Кассир** — принимает платежи, ищет клиентов, вводит показания
- **Бухгалтер** — работает с сальдо, начислениями, формирует отчеты, закрывает периоды
- **Администратор** — управляет справочниками, следит за событиями, добавляет сотрудников

## Техническая информация

Система работает через веб-интерфейс в браузере. Средства подключения - обычный ПК с доступом к внутренней сети офиса. Хранилище данных - база данных PostgreSQL.

Поддерживает работу с Excel-файлами для массового импорта платежей.

Проект разработан на языке Java с использованием Spring Boot framework.
